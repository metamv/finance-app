# Финансы

Личный учёт расходов, доходов и вложений в проекты. Работает в браузере, на телефоне
добавляется на главный экран как приложение.

- Счета в любых валютах, курсы — вручную или с биржи
- Категории с группами и подкатегориями, цвета для диаграмм
- Проекты: вложено / вернулось / итог
- Калькулятор, разделение чека, регулярные операции
- Данные хранятся в Supabase, синхронизируются между устройствами, работают без интернета

## Устройство

Без сборки: обычные файлы, Vue 3 и supabase-js подключаются из CDN.

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css` | страница и оформление |
| `js/main.js` | запуск, вкладки, шторки |
| `js/store.js` | данные и расчёты |
| `js/cloud.js` | вход и синхронизация с Supabase |
| `js/views.js` | экраны: Главная, Операции, Проекты, Настройки |
| `js/sheets.js` | формы: операция, счёт, проект, категория, регулярные |
| `js/ui.js`, `js/login.js` | мелкие элементы интерфейса, экран входа |
| `js/money.js` | валюты, даты, калькулятор |
| `supabase/setup.sql` | однократная настройка базы в Supabase |

Локальный запуск: `python -m http.server 5173` в папке проекта, затем http://localhost:5173.
